Задание 4 (Префиксный и постфиксный инкремент)
Объявите int a=5, b=5. Вычислите c = ++a и d = b++. Выведите a, b, c, d. В комментариях объясните разницу.
Важно: префиксный ++a сначала увеличивает a, затем возвращает новое значение. Постфиксный b++ сначала возвращает текущее значение b, затем увеличивает b.

#include <iostream>
using namespace std;

int main() {
    int a = 5, b = 5, c, d;
    c = ++a, d = b++;   //префиксный ++a сначала увеличивает a, затем возвращает новое значение. Постфиксный b++ сначала возвращает текущее значение b, затем увеличивает b.
    cout << a << ", " << b << ", " << c << ", " << d << endl;
}

Задание 5 (Декремент в цикле)
Напишите цикл for с использованием постфиксного декремента n-- для вывода чисел от 10 до 1.
Важно: в условии цикла используйте n > 0. Постфиксный декремент уменьшает переменную после использования её текущего значения.

#include <iostream>
using namespace std;

int main() {
    for (int i = 10; i > 0; i--) {
        cout << i << endl;
    }
}

Задание 7 (Логические операторы)
Для int a=5, b=10, c=15 вычислите: (a < b) && (b < c), (a > b) || (b < c), !((a + b) == c), (a == 5) && (b != 10) || (c == 15).
Важно: && (И) возвращает true только если оба операнда true. || (ИЛИ) возвращает true если хотя бы один операнд true. ! (НЕ) инвертирует значение. Приоритет: ! > && > ||.

#include <iostream>
using namespace std;

int main() {
    int a = 5, b = 10, c = 15;
    cout << ((a < b) && (b < c)) << endl << ((a > b) || (b < c)) << endl << (!((a + b) == c)) << endl << ((a == 5) && (b != 10) || (c == 15)) << endl;
}

Задание 8 (Тернарный оператор)
Запросите у пользователя два числа. Используя тернарный оператор, выведите максимальное из них.
Важно: тернарный оператор имеет вид (условие) ? значение_если_true : значение_если_false. Для ввода используйте cin >>.

#include <iostream>
using namespace std;

int main() {
    int a, b;
    cin >> a >> b;
    cout << ((a > b) ? a : b) << endl;
}

Задание 9 (Тернарный оператор со строкой)
Дано int age = 20. Используя тернарный оператор, присвойте переменной string status значение "Совершеннолетний" или "Несовершеннолетний" и выведите её.

#include <iostream>

Задание 10 (Оператор запятая)
Выполните фрагмент: c = (a = 5, b = 7, a + b); Выведите a, b, c. Объясните в комментариях работу оператора запятая.
Важно: оператор запятая выполняет все выражения по порядку и возвращает значение последнего. В данном примере c получит значение a + b (то есть 12).

#include <iostream>
using namespace std;

int main() {
    int a, b, c;
    c = (a = 5, b = 7, a + b);  //оператор запятая выполняет все выражения по порядку и возвращает значение последнего.
    cout << a << endl << b << endl << c << endl;
}

Задание 12 (sizeof для переменной)
Объявите переменные каждого типа: int, double, char, bool. Выведите размер каждой с помощью sizeof. Выведите размер выражения (a + b), где a и b — целые переменные.
Важно: sizeof можно применять как к типам (sizeof(int)), так и к переменным (sizeof(a)) и выражениям (sizeof(a + b)).

#include <iostream>
using namespace std;

int main() {
    int    a = 10;
    double b = 3.14;
    char   c = 'X';
    bool   d = true;
    int    e = 20;

    cout << "sizeof(int)    = " << sizeof(int)    << endl;
    cout << "sizeof(double) = " << sizeof(double) << endl;
    cout << "sizeof(char)   = " << sizeof(char)   << endl;
    cout << "sizeof(bool)   = " << sizeof(bool)   << endl;

    cout << "sizeof(a) = " << sizeof(a) << endl;
    cout << "sizeof(b) = " << sizeof(b) << endl;
    cout << "sizeof(c) = " << sizeof(c) << endl;
    cout << "sizeof(d) = " << sizeof(d) << endl;

    cout << "sizeof(a + e) = " << sizeof(a + e) << endl; // тип int
}

Задание 13 (Приведение типа C-style)
Дано double pi = 3.14159. Выполните приведение двумя способами: int pi_int = (int)pi; и int pi_int2 = int(pi); Выведите оба результата.
Важно: при приведении double к int дробная часть отбрасывается (не округляется!). Оба способа эквивалентны.

#include <iostream>
using namespace std;

int main() {
    double pi = 3.14159;
    int pi_int = (int)pi;
    int pi_int2 = int(pi);

    cout << "pi = " << pi << endl;
    cout << "(int)pi = " << pi_int << endl;
    cout << "int(pi) = " << pi_int2 << endl;
}

Задание 14 (Приведение с потерей данных)
Объявите float f = 9.99. Приведите к int, а затем к char. Выведите все три значения.
Важно: при приведении float к int дробная часть отбрасывается. При приведении int к char (если значение > 127) происходит переполнение, и результат может быть неожиданным (берётся младший байт).

#include <iostream>
using namespace std;

int main() {
    float f = 9.99f;
    int i = (int)f;
    char c = (char)i;

    cout << "float f = " << f << endl;
    cout << "int i = " << i << endl;
    cout << "char c = " << (int)c << endl;
}
